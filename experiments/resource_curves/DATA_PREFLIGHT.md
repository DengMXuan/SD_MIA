# 辅助数据消融预检查（2026-09-26）

现有实现位于 `experiments/resource_curves/`，是可组合调用的实验库，没有发现专门的
辅助数据量消融启动脚本。代码支持当前固定候选 B=2 主方法，改变的是检测器的数据量，
不改变目标模型或 KD 草稿的训练数据。接口用法见 [README.md](README.md)。

两条曲线分别保持另一个变量和测试集固定：

| 曲线 | 拟合总数（含验证） | 校准数 | 最大额外非成员需求 |
|---|---|---|---:|
| 拟合数据量 | 400、800、1200 | 固定 200 | 800 |
| 校准数据量 | 固定 400 | 200、600、1200 | 1000 |

拟合中的训练/验证按 80%/20% 划分，最大辅助总量为 1600。两个研究单独构建，
因此可复用同一扩展候选集，无需同时预留 1200 拟合和 1200 校准。

本次只读检查了 Qwen 三个数据集 × 三个 seed 的 epoch 1 条件：
`config.seed == config.data_seed == shared_split.seed` 均为各自的 1919、1949、1978，
护照记录的 shared split SHA-256 与实际文件相同。目标模型和 `draft_auxiliary_distilled`
的配置及索引所列权重分片均存在；没有加载或重新散列整套大模型权重。

原选择器存在独立默认 seed 20260922，现已改为继承冻结划分 seed。
扩展选样、study/point、观测采集、检测器拟合及指标 bootstrap 都检查同一条件 seed。
人工覆盖为其他 seed 会报错；旧的无 seed study/extension 应在新输出目录重建。

数据检查只加载冻结划分要求的五种本地 tokenizer，不加载语言模型。检查原始数据池
SHA-256 与冻结 shared split 一致，然后排除所有 6600 条已分配记录：2000 成员、
2000 测试非成员、2000 草稿辅助和 600 审计辅助。从余下 1400 条中，按条件 seed 选择，
对所有 tokenizer 执行 128–512 token 长度、原文/精确 token 重复和 13-gram 近似重复检查。
不会从测试集借数据，也没有修改原池或原划分。

预检查产物独立保存在 `/home/mxd/lib/SD_MIA-pretraining-data/resource_curves/`：

- `PREFLIGHT.json`：每个数据集/seed 的筛选结果、拒绝计数和来源哈希。
- `MODEL_CONDITIONS.json`：已核对的 epoch 1 目标/KD 模型条件与检查范围。
- `<dataset>/seed<seed>/extension/EXTENSION.json`：选定的 1000 条额外非成员及各 tokenizer 的响应哈希。
- 同条件的 `calibration/STUDY.json`、`fitting/STUDY.json`：两条曲线的固定测试和嵌套辅助角色。

这些文件可以在代码同步后继续使用；未来正式入口仍需核对对应模型护照，重新计算模型
指纹并加载匹配 checkpoint。数据预检查不等于完成正式消融，也没有产生大模型效果或计时结果。
CPU 测试覆盖 B=2 与共享主方法等价、各预算、划分互斥、校准曲线复用同一检测器、断点恢复
