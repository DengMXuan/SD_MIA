# Complete Qwen3 and Gemma 4 model-pair fine-tuning matrix

Status: accepted. The experiment covers two base model pairs—`Qwen/Qwen3-8B-Base` with `Qwen/Qwen3-1.7B-Base`, and `google/gemma-4-12B` with `google/gemma-4-E2B`—across the three frozen controlled-SFT pools (`wikitection`, `newstection`, and `arxivtection`), target epochs 1 and 3, and condition seeds 1919, 1949, and 1978. A condition uses the same seed for data construction and stochastic training; each pair therefore has 18 conditions.

Each condition uses 2,000 member, 2,000 nonmember, and 2,000 disjoint auxiliary records. Target SFT and the member-trained draft use member records only. The KD draft starts from the base draft, uses the member-SFT target as teacher, and trains only on auxiliary records with the existing 384-step temperature-2.0 objective (`0.2 CE + 0.8 KL`). The member-trained draft follows the target epoch setting. Both pairs use text-only training with the existing fixed `SFT_PROMPT`, masked prompt labels, appended EOS, bf16 full-parameter updates, paged 8-bit AdamW, learning rate `2e-5`, per-device batch size 2, gradient accumulation 8, and gradient clipping 1.0.

The same condition seed is shared within a pair, while the tokenizer-specific token-band and deduplication process may select different raw records across pairs. Model files are downloaded to the Hugging Face cache and fixed to the download-time commit revision; Qwen conditions start from the cached base checkpoints and do not reuse prior `20260824` SFT results. Four exclusive workers use GPUs 3–6, one condition per GPU. The first condition is a complete Gemma smoke test (`newstection`, epoch 1, seed 1919); only after it succeeds does the remaining matrix start. Each condition produces three final full checkpoints, yielding 54 per pair and 108 overall; intermediate checkpoints and downstream audit evaluation are out of scope.
