# 论文实验展示方案

本文整理四组实验的图表展示建议：有效性、计算效率、鲁棒性、预训练场景扩展。当前范围不包含消融实验。本方案用于讨论和规划，不代表实验已经完成或结果已经支持预期结论。

总体原则：**表格给出完整结果，曲线展示变化规律，少量诊断图解释差异。** 图形选择以实验要回答的问题为依据。

图形参考：[Seaborn Example Gallery](https://seaborn.pydata.org/examples/index.html)。

## 一、整体配置

| 实验 | 要回答的问题 | 推荐正文展示 | 可选或补充材料 |
| --- | --- | --- | --- |
| 1. 有效性 | 主方法是否优于基线，能否扩展到其他推测解码架构？ | 主结果表＋MTP/EAGLE-3 小表 | 低 FPR 区域的 ROC 曲线 |
| 2. 计算效率 | 达到一定性能需要多少查询，实际运行需要多久？ | 性能—查询预算曲线＋耗时水平条形图 | 性能—耗时图、单样本延迟分布 |
| 3. 鲁棒性 | 不同 DP 隐私预算下，主方法的性能如何变化？ | 四指标随 ε 变化的 2×2 分面折线图 | 隐私、模型效用与攻击性能的联合分析 |
| 4. 预训练场景扩展 | 在真实预训练场景中是否有效，是否依赖特定数据来源？ | 结果表＋MIMIR 跨来源点图 | 方法与来源较多时使用热力图；攻击分数分布图 |

四项指标统一为 **AUC、pAUC、TPR@1%FPR、TPR@10%FPR**。pAUC 需明确积分区间和是否标准化，例如沿用项目的 pAUC@10% 定义。

## 二、有效性实验

### 2.1 主要比较：Qwen3、Gemma 与基线方法

**目的：** 判断主方法在不同模型和数据集上是否优于基线，以及优势是否体现在低误报区域。

**首选展示：主结果表。**

- 行：主方法与各基线方法。
- 分块：模型、数据集；条件较多时拆成多个面板或表格。
- 列：四项指标。
- 重复实验：根据统一统计口径报告均值及波动或置信区间。
- 标明各方法所需的信息访问权限，帮助读者理解比较条件。

基线较多时，四个指标再乘以模型和数据集会使分组条形图过于密集。主表更适合提供完整、准确的比较结果。

**辅助展示：分面 ROC 曲线。**

- 横轴为 FPR，纵轴为 TPR。
- 按模型分面；必要时进一步按数据集分面。
- 重点展示 FPR≤10% 的区域，并标出 1% 和 10% FPR。
- 正文可展示主方法与少数有代表性的基线；提前确定入图规则，完整结果保留在表格或附录。
- 如果正文空间有限，ROC 曲线放入附录。

### 2.2 架构扩展：MTP 与 EAGLE-3

**实验对象：** Qwen3.5 + MTP、Llama + EAGLE-3。

**首选展示：独立的小表。**

- 行：模型与推测解码架构；有基线结果时增加方法行。
- 列：四项指标。
- 保留主方法结果，基线比较根据时间安排作为可选内容。

只有主方法结果时，小表仍然可以完整表达跨架构验证结果，无需额外构造比较图。

## 三、计算效率实验

**实验对象：** 在 Qwen3 上比较主方法与基线方法。

需要分别回答两个问题：达到某种效果需要多少查询，以及实际运行需要多久。

### 3.1 性能与查询预算

**首选展示：分面折线图。**

- 横轴：查询预算。
- 纵轴：攻击性能。
- 颜色与线型：区分方法。
- 完整方案：四项指标组成 2×2 子图。
- 紧凑方案：正文保留 pAUC 与 TPR@1%FPR，其他指标放入附录。
- 只有单个预算配置的方法用点表示，不人为连成曲线。

重点观察：相同预算下的性能、达到相近性能所需的预算，以及增加预算后的边际收益。

**预算口径：** 接受判定次数不等于目标模型调用次数。跨基线比较时需明确共同预算单位；无法统一的成本分别报告，再以实际耗时作为共同参照。对于主方法，应区分每个候选位置的查询次数与每条记录的总查询次数。

### 3.2 实际运行时间

**首选展示：水平条形图。**

- 纵轴：方法。
- 横轴：耗时。
- 方法可按耗时排序。
- 推荐分成两个面板：准备与校准成本、平均每条测试记录的审计耗时。

如果需要展示成本构成，可以对同一批测试记录的端到端总耗时做堆叠条形图，拆成准备、校准、测试三个阶段。不能把一次性总耗时与单样本耗时直接堆叠。

### 3.3 可选展示

| 图形 | 设计 | 用途 |
| --- | --- | --- |
| 性能—耗时散点图或折线轨迹图 | 横轴实际耗时，纵轴 pAUC；不同点对应不同预算 | 展示性能与实际成本的权衡 |
| 单样本延迟箱线图 | 每种方法对应一组单样本耗时 | 展示延迟波动和长尾，而不只报告平均值 |

计时需统一硬件、批量大小、输入长度处理和预热口径，并明确缓存及检测器拟合是否计入成本。

## 四、鲁棒性实验

**目的：** 评估不同差分隐私预算下主方法的有效性。

### 4.1 主图：隐私预算—性能曲线

推荐一张 **2×2 分面折线图**：

| 子图 | 横轴 | 纵轴 |
| --- | --- | --- |
| 左上 | 隐私预算 ε | AUC |
| 右上 | 隐私预算 ε | pAUC |
| 左下 | 隐私预算 ε | TPR@1%FPR |
| 右下 | 隐私预算 ε | TPR@10%FPR |

展示约定：

- 固定 δ，明确 ε 越小、隐私保护越强。
- 使用实际部署的目标与草稿组合隐私预算，明确不同部署方式的会计口径。
- 无 DP 结果画成水平参考线，不把 ε=∞ 当作普通数值连接到曲线末端。
- 每个实测 ε 画出数据点，重复实验用误差线或置信带表达不确定性。
- 若展示 Qwen 和 Gemma，可用两条曲线；如果还区分草稿适配方式，优先增加分面，避免曲线过多。

折线图能够直接表达随隐私预算变化的趋势，因此比条形图更适合作为这一节的主图。

### 4.2 可选：模型效用分析

若有相应测量，可增加隐私预算、模型效用与攻击性能的联合分析，用于判断攻击性能下降时模型是否仍然可用。该内容需要额外测量模型效用，不作为当前必选项。

## 五、预训练场景扩展

**实验对象：** Qwen 上的时间划分数据集，以及 Pythia 上的 MIMIR 基准。

需要回答：主方法在预训练数据上是否有效，以及效果是否依赖某个数据来源。

### 5.1 完整结果：分区块表格

**首选展示：结果表。**

- 分成 Qwen 时间划分与 Pythia/MIMIR 两个区块。
- 各区块报告四项指标。
- 按实际完成情况列出主方法与基线方法。

不将两种实验直接合成一个平均值：Qwen 的时间划分属于成员身份的代理标签，Pythia/MIMIR 提供训练集来源标签，分别报告可以保留两者的证据边界。

### 5.2 跨数据来源：点图或热力图

**首选展示：带误差线的点图。**

- 一个轴表示 MIMIR 数据来源，另一个轴表示性能。
- 用不同点形或颜色区分方法。
- 多指标使用独立面板，明确各指标数值。
- 适合观察来源之间的差异与不确定性。

**替代方案：热力图。** 当方法和数据来源都较多时采用：

- 行：方法。
- 列：数据来源。
- 颜色：同一项指标，例如 pAUC。
- 四项指标需要四个面板，并分别明确色标口径。
- 不按行单独归一化，以免丢失绝对性能差异。

### 5.3 可选：攻击分数分布

可以用 ECDF、直方图或小提琴图比较成员与非成员的攻击分数，解释不同数据来源上的可分性差异。

这些分布图用于辅助解释。低 FPR 区域的检测能力仍以 ROC 和相应指标为主要证据。

## 六、其他图形的适用性

| 图形 | 建议 | 理由与适用条件 |
| --- | --- | --- |
| 雷达图 | 不建议作为正文主图 | 四项指标相关性较高；雷达面积缺少明确统计含义；即使数值都在 0–1 区间，含义也不同，不利于精确比较 |
| 小提琴图 | 用于大量样本的攻击分数分布，可放补充材料 | 适合观察分布形态，但不适合仅有少数随机种子的指标结果，也不如 ROC 清楚地呈现低 FPR 尾部 |
| 箱线图 | 用于有足够重复测量的单样本延迟 | 适合展示离散程度、长尾与异常值 |
| 散点＋均值或区间 | 用于少量随机种子的结果 | 例如仅有三个种子时，直接展示三个点比拟合小提琴分布更透明 |
| 热力图 | 用于密集的“方法×数据来源”比较 | 最适合 MIMIR 跨来源结果；保持绝对数值和色标可比较 |
| 分组条形图 | 少量方法、少量条件时可用 | 方法、模型、数据集和指标同时增加时容易过密，完整结果优先使用表格 |

## 七、统一图表规范

1. **方法编码一致：** 同一种方法在所有图中使用相同颜色，并配合线型或点形区分。
2. **指标定义一致：** 明确 pAUC 的范围和标准化方式；区分经验 ROC 上的 TPR@FPR 与独立校准阈值下的 TPR、实际 FPR。
3. **不确定性口径明确：** 图注注明误差线表示跨种子波动还是样本重采样置信区间，避免混用。
4. **比较条件明确：** 统一数据划分及对应实验条件；注明方法访问权限、预算与计时口径。
5. **正文与附录分工：** 正文突出完整结果和主要变化趋势；附录容纳完整 ROC、额外指标曲线与分布诊断。
6. **避免重复表达：** 同一组结果不重复制作表格、条形图、雷达图；新增图形应回答新的问题。
